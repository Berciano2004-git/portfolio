# Portfolio de Carlos Berciano Cabezas

Portfolio personal actualizado sobre la base de los archivos originales.

## Tecnologías
- HTML5 semántico
- Bootstrap 5.3.3
- CSS personalizado
- JavaScript
- Bootstrap Icons

## Ejecutar en local
Abre `index.html` en un navegador. Para trabajar con Live Server, abre la carpeta del proyecto en Visual Studio Code y ejecuta Live Server desde `index.html`.

## Antes de publicar
- Comprueba los enlaces de tus repositorios y añade enlaces reales a las prácticas académicas si las publicas.
- Añade capturas propias de los proyectos y enlaces a los repositorios de las prácticas si los publicas.
- Revisa los datos de contacto antes de publicar.
- La fotografía del perfil es la imagen que has proporcionado.
- El CV se incluye en `assets` si se ha podido incorporar desde el archivo adjunto.

## Uso de asistencia
Se ha utilizado asistencia de IA para revisar y actualizar parte del HTML, CSS y JavaScript, reorganizar la presentación y adaptar el diseño a Bootstrap 5.3. Revisa, comprende y personaliza el código antes de entregarlo.

## Contenido del portfolio
La experiencia profesional incluye E-računi (Eslovenia), Cartake Back y una experiencia de un mes en hostelería. Las certificaciones de socorrista y monitor de natación aparecen separadas de la experiencia laboral. Las actividades de JavaScript, DOM y Apache se identifican como prácticas formativas, no como empleos.
